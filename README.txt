# 学校野菜 POSレジ

## 使い方
1. index.html をブラウザで開く
2. 「商品管理」でバーコード・商品名・価格・在庫を登録
3. USBバーコードリーダーをPCに接続
4. 「レジ」でバーコードをスキャン
5. カゴに商品が入り、「会計確定」で在庫と売上を更新
6. 「売上・在庫」で集計を確認

## サンプル
「商品管理」→「サンプル商品を入れる」でテスト商品を登録できます。

## バーコードリーダー
一般的なUSBタイプのキーボードエミュレーション方式に対応。
バーコードを読むと数字が入力され、末尾にEnterが送られる設定なら自動的に商品追加されます。

## 注意
この初版はブラウザの localStorage 保存です。
同じPC/ブラウザ内では使えますが、複数レジ・複数スマホでリアルタイム共有するにはFirebase等のクラウドDB版に変更してください。
